# Coffee Card Agent Guide

## Project

- Flutter application using Dart 3.12 or newer.
- Application code lives in `lib/`; tests live in `test/`.
- Keep platform directories generated by Flutter unless a platform-specific
  change is required.
- Use the relevant instructions in `.agents/skills/` for Flutter and Dart work.

## Development

Run these commands from the repository root:

```sh
flutter pub get
dart format .
flutter analyze
flutter test
flutter run
```

## Code Standards

- Follow `analysis_options.yaml` and keep analyzer output clean.
- Prefer small, focused widgets and `const` constructors where possible.
- Use clear app-specific class names; avoid names exported by Flutter itself.
- Do not use `print` in production code; use `debugPrint` for temporary
  development diagnostics or a logging package for persistent logging.
- Add or update tests whenever behavior changes.
- Never commit generated output, local environment files, or signing secrets.

## Verification

Before completing a change:

1. Format changed Dart files.
2. Run `flutter analyze`.
3. Run the relevant tests, or `flutter test` for project-wide changes.
